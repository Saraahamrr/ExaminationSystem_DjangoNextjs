🎓 Graduation Project – ITI
A full-stack platform built with Django (backend) and Next.js (frontend) to manage and streamline exams, notifications, and student-instructor interaction.

🚀 Installation and Usage

🔧 Prerequisites
Python 3.8+ (for the Django backend)

Node.js 16+ (for the Next.js frontend)

PostgreSQL (assumed database)

Git (for cloning the repository)

⚙️ Backend Setup
Clone the repository

```
git clone https://github.com/FarhaMokhtar/Graduation_Project_ITI
```
Navigate to the backend directory

```
cd backend
```
Create a virtual environment

```
python -m venv venv
```
Activate the virtual environment

On Linux/Mac:
```
source venv/bin/activate
```
On Windows:

```
venv\Scripts\activate
```
Install dependencies

```
pip install -r requirements.txt
```
Configure environment variables
(e.g., DATABASE_URL, Google OAuth credentials, email service settings)

Run migrations

```
python manage.py migrate
```
Start the Django development server

```
python manage.py runserver
```
🌐 Frontend Setup
Navigate to the frontend directory

```
cd frontend
```
Install dependencies

```
npm install
```
🖥️ Running the Platform
Frontend: http://localhost:3000

Backend API: http://localhost:8000
